# CACTIxT
CACTIxT is a CACTI-compatible framework suitable for performing design space explorations of SRAM-based structures at the architecture level.
It models 6T, 8T, and 10T bitcells; models all the peripheral circuitry, taking into account the peculiarities of each cell topology.
This framework estimates area, delay, dynamic and leakage power with high accuracy.
