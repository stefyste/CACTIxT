# En-CACTI
En-CACTI is a framework suitable to perform design space explorations of SRAM-based structures at the architecture level.
It models 6T, 8T, and 10T bitcells; models all the peripheral circuitry, taking into account the peculiarities of each cell topology.
This framework estimates area, delay, dynamic and leakage power with high accuracy. 
In its current release, it integrates the 14nm and the 22nm 0.8V predictive technology models. 
Future releases, already under development, will also include commercial technology nodes.
